CSV Format Guide

Your CSV file should have the following column headers:

name,day_of_week,start_time,end_time

Jane Smith,Tuesday,13:00,17:30

Notes:

  • day_of_week must be one of: Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday.
  • Times must be in 24-hour format (HH:MM).
  • Each row represents one availability block.
